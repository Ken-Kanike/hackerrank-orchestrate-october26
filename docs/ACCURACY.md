## Ablations (one switch off, 518 outputs compared)
| Configuration | Recall | Outputs changed |
|---|---|---|
| default | 0.969 | 0 |
| no workflow-run alignment | 0.943 | 154 |
| lenient time model | 0.969 | 0 |
| no lineage | 0.969 | 0 |
| no activity checks | 0.969 | 0 |

Strict time, lineage and activity checks are guards for data variants (each proven by an end-to-end scenario). Alignment is the load-bearing heuristic and is dataset-specific (documented).

## Other checks
* **Link recovery** (label-free): hide an identity-proven account, re-derive it from activity: about 99%.
* **8 end-to-end scenarios** with hand-written expected outputs, each failing when its feature is switched off.
* **Ghost sweep** found the only output change versus the hand-off (case_34).
* **Browser parity**: the in-browser run over the full dataset equals the CLI `output.csv` row for row (`webui/tests/test_ui.py --full`).

## Honest limits
17 account links are deterministic guesses (flagged); 12 catalog-only cases use a family-default state without a vision key (flagged); time windows were set from the samples; the intent lexicon was written while seeing the evaluation texts (48 independent probes exist).
